# EA Part 2 — Businesses

**Читать: https://maryline07.github.io/ea-part2/**

Двуязычный (русский / английский) учебный курс подготовки к экзамену
IRS Special Enrollment Examination, часть 2 «Businesses».

**Налоговый период — 2025.** Право по состоянию на 31 декабря 2025 года.
Экзаменационное окно: 1 июля 2026 — 28 февраля 2027.

## Что это

Двадцать модулей от выбора формы бизнеса до освобождённых организаций.
В каждом: правила с таблицами, расчётные примеры, разбор типичных ошибок,
задачи для самопроверки и тренажёр, где объясняется не только верный ответ,
но и причина неверности каждого остального.

Переключатель RU / EN меняет язык всей страницы. Английская версия — не
перевод русской: правило даётся в формулировках IRS, потому что экзамен
спрашивает именно так. Русская версия объясняет логику нормы и разбирает
места, где формулировка вводит в заблуждение.

Рядом — переключатель светлой и тёмной темы. Пока кнопка не нажата,
страница следует настройке системы; нажатие фиксирует выбор. Полезно, когда
читаете подолгу и вечером.

## Как открыть

Двойным кликом по `index.html`. Ни сервера, ни сборки, ни установки
зависимостей не требуется — это статические страницы на HTML, CSS и
ванильном JavaScript.

Для публикации все страницы собираются в один файл:

```
python build_artifact.py
```

Результат — `ea-part2.html`, автономный документ со всеми модулями и
навигацией внутри. Сборщик прерывает работу, если находит в исходниках
название коммерческого учебного курса.

## Откуда взяты сведения

Материал написан самостоятельно на основе Кодекса внутренних доходов,
регламентов Казначейства и публикаций Службы внутренних доходов США.
Эти документы находятся в общественном достоянии.

Ни одно число, ставка, порог или срок не попадает в материал без сверки с
irs.gov. Все величины собраны в `assets/figures-2025.js`, у каждой указана
публикация-источник, и страница «Справочник 2025» показывает её рядом со
значением. Величина, которую не удалось подтвердить, не публикуется.

Отдельного внимания требует год. Закон, подписанный 4 июля 2025 года,
изменил часть норм посреди года, а часть — только начиная с 2026 года.
Действующая сегодня редакция публикации IRS может показывать величину, к
периоду 2025 не относящуюся. Пример из модуля 1: порог формы 1099-NEC для
2025 года — $600, а не $2 000.

## Структура

```
index.html          карта модулей
reference.html      числа, ставки и сроки 2025 с источниками
exam-map.html       официальная программа экзамена и покрытие курса
sources.html        источники, методология, отказ от ответственности
su01.html … su20.html   модули
assets/
  style.css         оформление
  app.js            переключение языка, тренажёр, прогресс
  figures-2025.js   числовой справочник
build_artifact.py   сборка в один файл
```

Прогресс по тренажёрам и выбор языка хранятся в браузере читателя и никуда
не передаются.
